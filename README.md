# C8T1 - Sistema de Gestión de Inventario y Pedidos (Reto 2)

## Descripción
Aplicación desarrollada en Python 3.x orientada a la gestión básica de inventarios y pedidos comerciales, haciendo uso de **arreglos unidimensionales (listas paralelas)**, funciones modulares, procedimientos de control, estructuras condicionales y bucles interactivos.

## Funcionalidades Implementadas
1. **Registro**: Permite dar de alta nuevos productos o pedidos validando códigos únicos y tipos de datos numéricos.
2. **Listado**: Muestra en formato de tabla formateada el contenido completo de los arreglos unidimensionales mediante iteración por índices.
3. **Edición**: Facilita la modificación interactiva de atributos específicos de cualquier registro existente.
4. **Eliminación**: Remueve de forma sincronizada los elementos de las listas paralelas según su posición en el índice.

## Requisitos y Criterios de Evaluación Cubiertos
* **Uso de Arreglos Unidimensionales:** Manejo eficiente de listas paralelas (`codigos`, `nombres`, `cantidades`, `precios`).
* **Implementación de Funciones:** Estructuración modular mediante procedimientos y funciones puras para cada acción del sistema.
* **Calidad del Código:** Código limpio, documentado mediante *docstrings*, nombres descriptivos en español y manejo robusto de excepciones (`try-except`).
